# Ecommerce Website

Welcome to the Ecommerce Website project built with the MERN stack (MongoDB, Express, React, Node.js). This application provides a full-stack solution for managing an online store, featuring product management and payment processing.

## Live Demo

You can view the live application at: [Ecommerce Website](https://ecommerce-website-mern-rho.vercel.app/)

## Features

- **Product Catalog**: Browse and manage a variety of products.
- **Shopping Cart**: Add products to your cart for easy checkout.
- **Payment Processing**: Secure payment integration for transactions.
- **User Interface**: Clean and responsive design built with React.

## Technology Stack

- **Frontend**: 
  - React
  - JavaScript
  - CSS
  - HTML

- **Backend**: 
  - Node.js
  - Express.js

- **Database**: 
  - MongoDB

- **Deployment**: 
  - Vercel

## Installation

To run this project locally, follow these steps:

1. Clone the repository:
   ```bash
   git clone https://github.com/saikrishnamamidi2003/ecommerce-website-mern.git
   ```
2. Navigate to the project directory:
   ```bash
   cd ecommerce-website-mern
   ```
3. Install the dependencies:
   ```bash
   npm install
   ```
4. Start the server:
   ```bash
   npm start
   ```
